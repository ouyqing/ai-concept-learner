# 概念学习资料生成 Skill

针对用户给出的**任意概念**，生成一份结构化、可验证、可复查的学习资料文档。本 Skill 不限定领域：技术、科学、人文、商业等任何概念均可作为输入。

## 适用场景

- 用户给出一个新概念（如"RAG"、"熵"、"供应链金融"），希望获得系统学习资料。
- 用户已有零散资料，需要按统一结构整理为一份概念笔记。
- 用户要求对比、辨析易混淆概念，并附可追溯的来源链接。

触发示例："帮我整理一下 XXX 概念"、"我想学习 XXX"、"生成 XXX 的概念文档"。

不适用：用户只想要一句话定义、或要求生成与概念学习无关的内容（如代码实现、翻译整篇文章）时，不触发本 Skill。

## 输入信息

必填：

- **概念名称**：待学习的概念，任意领域均可（如 Agent、Context、Skill、马尔可夫链、期权）。

可选（缺失时按默认值处理，不要向用户追问）：

- **领域/背景**：默认根据概念名称自行判断；若概念存在多种含义（如"线程"在编程与纺织中的含义），列出 2–3 种主要含义，选择最常见或最可能是用户所指的一 种生成，并在文档开头注明这一选择。
- **目标读者**：默认为"刚接触该领域的初学者"。
- **深度**：默认为"入门到进阶"，即初学者能读懂，又包含足够机制细节。
- **输出语言**：默认与用户提问语言一致；术语首次出现时给出英文原文（若有）。

## 生成步骤

按以下顺序执行，每步完成后再进入下一步：

1. **理解与拆解**：判断概念所属领域和是否存在歧义；拆解出该概念的 3–6 个关键子概念（作为"核心机制"的骨架）。
2. **联网检索**：使用 WebSearch / WebFetch 检索权威来源（要求见"资料来源要求"），收集定义、机制、实例、易混淆概念。至少覆盖 2 个独立来源后再动笔。
3. **撰写五个板块**：按"输出结构"逐段撰写，各板块要求见下文。写作遵循费曼技巧：先让自己"教会"一个外行，再落笔。
4. **自检**：对照"自检要求"逐项检查，不通过则修改后重查。
5. **输出**：将完整文档保存为 Markdown 文件（命名建议：`<概念名>.md`，中文概念用中文名），并在回复中给出文件路径与内容摘要。

## 输出结构

生成的概念文档必须包含以下五个板块，按此顺序：

### 1. 个人解释

- 用自己的话重述概念，禁止直接复制来源原文。
- 1–2 段，不超过 200 字；假设读者完全没有该领域背景，不得使用未解释的行话。
- 允许且鼓励使用一个贴近生活的类比（类比须标注"类比，仅在 XX 方面成立"）。

### 2. 核心机制

- 说明该概念"是什么、怎么运作"：关键组成部分、工作原理、与其他概念的依赖关系。
- 使用条目或简短小节组织，每个关键子概念一句话讲清。
- 该概念存在量化规律或标准定义时，给出精确定义（含公式/标准编号，若有）。

### 3. 应用场景

- 至少 3 个真实、具体的应用场景，避免空泛（不写"广泛应用于各行各业"这类句子）。
- 每个场景包含：谁在什么情况下用它、解决什么问题。
- 如实标注该概念的典型失效或不适配情况（若有）。

### 4. 边界辨析

- 列出 2–4 个与本概念最易混淆的概念，逐一说明区别（"A 是 X，而 B 是 Y"的对照式写法）。
- 指出该概念的适用边界：什么时候用它是对的，什么时候是误用。
- 点出 1–2 个常见误解并纠正。

### 5. 来源链接

- 以列表给出本文档事实性内容所依据的来源，每条格式：`[标题](URL) — 来源类型`。
- 至少 3 条，且满足下方"资料来源要求"。
- 附注检索日期（格式：YYYY-MM-DD）。

## 资料来源要求

- **优先级**：官方文档 / 标准规范 / 教材与论文 / 权威百科（如维基百科、Stanford Encyclopedia 等）/ 知名厂商技术博客，从高到低选用；博客、论坛帖子只能作为补充，不得作为关键事实的唯一依据。
- **数量与独立性**：至少 3 条来源，其中至少 2 条来自相互独立的站点。
- **交叉验证**：定义、数据、年份等关键事实必须有 2 个以上来源一致才可写入；来源之间冲突时，采用更权威的一方，并在文档中注明分歧。
- **可追溯**：只引用通过 WebSearch / WebFetch 实际获取到内容的 URL；禁止凭记忆编造或拼接链接。
- **时效**：优先选择近 2 年内的来源；概念本身更新很快（如 AI 领域）时，必须检索最新资料而非依赖旧知识。
- **诚实标注**：无法核实的内容，明确写"未能核实"或不写入，不得伪装成已验证事实。

## 自检要求

输出前逐项检查，全部通过才能交付：

- [ ] 通用性：输入换任意领域的新概念，本文档结构与流程依然适用（自检本次是否因概念特殊而跳过了某板块）。
- [ ] 费曼检验：个人解释部分不依赖任何未解释的术语；一个外行能复述出概念大意。
- [ ] 结构完整：五个板块齐全，顺序正确，无遗漏。
- [ ] 边界清晰：边界辨析至少对比了 2 个易混淆概念，并纠正了至少 1 个误解。
- [ ] 来源合规：≥3 条、≥2 个独立站点、含检索日期、链接均在本次会话中实际获取过。
- [ ] 事实可靠：所有关键断言可对应到至少一条来源；无编造链接、无未标注的猜测。
- [ ] 语言一致：全文语言与用户提问语言一致，关键术语标注英文原文（若有）。
