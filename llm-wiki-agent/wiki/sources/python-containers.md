## Summary
概念学习资料《Python 容器（list/tuple/dict/set）》。对比四类容器的语法、可变性、有序性与典型场景，强调按用途选容器。

## Key Claims
- list 可变长队列、tuple 只读队列、dict 键值对、set 去重桶
- dict/set 查找 O(1)；list 查找 O(n)
- Python 3.7+ dict 保留插入序
