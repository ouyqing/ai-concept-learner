1个人解释

Python 给你的"数据抽屉"分四类：列表（list）可变长队列、元组（tuple）只读队列、字典（dict）键值对柜子、集合（set）去重桶。选错了效率差 100 倍。

2核心机制

四类对比

类型语法可变？有序？典型用途
list[1,2,3]✓✓动态数组、可增删
tuple(1,2,3)✗✓不可变记录、字典 key
dict{'a':1}✓插入序（3.7+）键值查找
set{1,2,3}✓✗去重、集合运算

遍历

scores = [85, 92, 78] for i, s in enumerate(scores): print(f"第 {i+1} 名：{s}")

3应用场景

  1. 学生成绩排序：list 装分数、sorted() 排序
  2. 单词计数：dict 计频、Counter 工具
  3. 去重：list → set → list
  4. 查表：dict 用姓名查成绩

4边界辨析

常见误解：用 list 频繁查找 = 慢。list 是 O(n) 线性查找，dict 是 O(1) 哈希查找。要"判断某元素是否在容器中"，用 set/dict 更快。
